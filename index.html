Put your alerts on stream

StreamElements is already connected to your Twitch, so follows, subs, gift subs, cheers and raids all work with no extra setup.

First time only:

  1. Open StreamElements → My overlays and open your overlay (or click New overlay, 1920×1080).
  2. Click + → Static / Custom → Custom widget.
  3. On the left, click Open editor → JS tab → select everything (Ctrl+A) → paste (Ctrl+V) → Done.
  4. Under Position, size & style, set the widget to 1920 × 1080 at 0, 0.
  5. Click the overlay's Save button (top right). Don't skip this: Done alone doesn't save.
  6. If that overlay isn't in OBS yet, copy its link (🔗 at the top) into a Browser source.

Test: click Emulate in the StreamElements editor, or type !testalert all in your chat.
Changed a design later? Copy again and paste over the JS tab. Nothing changes in OBS.

Code won't save in StreamElements?

Make sure you click Done in the code editor and then the overlay's Save button (top right). If it still won't save, the code is too big. Use this tiny version instead. Your designs load from your GitHub Pages site.

Streamer.bot is logged into Twitch as you, so it sees every follow, sub, resub, gift sub, gift bomb, cheer and raid, including the same viewer cheering 1 bit again and again. You don't need any Streamer.bot actions.

  1. In Streamer.bot: Platforms → Twitch, connect your Broadcaster account (you've likely done this already).
  2. Servers/Clients → WebSocket Server: tick Auto Start and click Start Server. (Already on if you use Perfect Landing.)
  4. In OBS: add a Browser source → tick Local file → pick the file → 1920 × 1080 → tick Control audio via OBS.
  5. Test: type !testalert all in your chat.

If your dog alerts are also in StreamElements, delete that custom widget or every alert will play twice.
