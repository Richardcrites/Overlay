Export overlay for OBS

Creates one self-contained .html file with every alert, your dogs and sounds baked in.

Subs, resubs, gift subs, cheers and raids come straight from your chat. No login needed.

Follow alerts (optional, needs a Twitch token)

Twitch only shares follows with a token that has the moderator:read:followers scope. See the README for a 2-minute setup.

The exported file contains your token if you entered one. Don't share it.

How do I add it to OBS?
  1. In OBS, add a Browser source.
  2. Tick Local file and pick the downloaded .html.
  3. Set width 1920, height 1080.
  4. Tick Control audio via OBS so the alert sounds get their own mixer slider.
  5. Type !testalert all in your chat to try it.
